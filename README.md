✨ Funzionalità
Design Responsive & Moderno: Interfaccia curata nei dettagli, ottimizzata per la visualizzazione fluida su qualsiasi dispositivo (desktop, tablet e mobile)[cite: 1].
Internazionalizzazione (i18n): Supporto multilingua integrato per raggiungere un pubblico globale.

Struttura Modulare: Organizzazione pulita dei componenti CSS (tokens.css, animations.css, base.css, components.css) e della logica JavaScript[cite: 1].

🛠 Tecnologie
HTML5: Struttura semantica della pagina[cite: 1].
CSS3: Layout avanzati (Grid, Flexbox), stili personalizzati, variabili di design e animazioni fluide[cite: 1].
JavaScript (ES6+): Gestione della logica, interattività dinamica, configurazioni e localizzazione[cite: 1].

Ambiente & Test: Node.js, script di sviluppo dedicati e test suite integrati.

supabase/: Schema SQL e configurazioni per il database.
tests/: Test di unità e di progetto.
scripts/: Strumenti di supporto e server di sviluppo locale.
